# 🐱 chasing-tail (꼬리잡기)

한국어 멀티 **암살자/꼬리잡기 미니게임** Paper 플러그인. Minecraft **1.21**용.

각 플레이어는 **비밀 타겟**을 지정받고, 마지막까지 살아남는 플레이어가 승리합니다.

## 🎮 게임 방식

- `/꼬리잡기 시작` 으로 **2~8명** 참가해 게임 시작
- 각 플레이어는 **고유 색상**과 **비밀 타겟**을 부여받음 (타겟 체인이 순환하며, 마지막 플레이어는 첫 번째를 추적)
- **접근 판정** — **다이아몬드 2개를 손에 들고 우클릭**하면 타겟 대략 방향(앞/뒤/왼쪽/오른쪽)을 액션바에 표시 (다이아몬드는 소모되지 않음)
- **자신의 타겟만 처치**해야 하며, 타겟을 처치하면 그 사람의 타겟을 이어받음
- 잘못된 사람(자신의 타겟이 아닌)을 처치하면 실패 메시지 발생
- **마지막 1명이 남으면 승리** 판정, 게임 자동 종료

## 🛠 요구사항

- **Minecraft:** 1.21 (Paper/Spigot)
- **Java:** 21
- **빌드:** Maven

## 💾 설치 / 빌드

```bash
mvn clean package
```

생성된 `target/*.jar` 를 서버의 `plugins/` 폴더에 넣고 서버를 재시작합니다.

## 🕹 명령어

| 명령어 | 설명 | 권한 |
|--------|------|------|
| `/꼬리잡기 시작` | 꼬리잡기 게임 시작 | `chasingtail.start` |

## 📁 소스 구조

```
src/main/java/io/github/freecad1211/chasingtail/
├── Chasingtail.java          # 메인 플러그인 + 게임 로직
├── GameCommandExecutor.java  # 명령어 처리
├── GameEventListener.java    # 플레이어 처치/사망 이벤트
└── Messages.java             # 채팅 메시지 포맷
```
